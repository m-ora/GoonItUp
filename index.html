Reddit API

Anonymous JSON is blocked, so this page uses Reddit RSS by default. Connect a personal app if you want deeper paging, more videos, and NSFW listings your account can see.

  1. Open reddit.com/prefs/apps
  2. Create an app. Type can be script or web app.
  3. Redirect URI: http://127.0.0.1:8765/oauth
  4. Paste the client id (and secret if it has one), then connect.
